# TOOM

用 Odin 写的终端视频会议。H.264 与 Opus 经 UDP 走一个小 SFU 中转，所有画面经 [Aideo](https://github.com/zyoung11/Aideo) 渲染引擎用 sixel 画进终端，引擎以静态库形式内置。客户端与服务端合在一个二进制里。

## 工作方式

- 每个客户端只连服务端，所有数据经服务端中转，没有点对点路径
- UDP 单端口，默认 4400。入会是 HMAC-SHA256 挑战应答，以会议码为密钥
- 媒体走 XChaCha20-Poly1305 端到端加密，服务端只转发密文
- 摄像头块 4:3，共享块 16:9 或 16:10。框固定，开关摄像头边框不动

## 特性

- 终端内 sixel 视频、屏幕共享、系统音频共享
- H.264 走 x264、NVENC 或 VAAPI，运行时探测回退 x264
- Opus 音频加 WebRTC 回声消除
- 网格与焦点布局，按键与边框可配置
- 静态二进制，任何 glibc 发行版都能跑

## 构建

依赖：`odin`、`cc`、`git`、`cmake`、`meson`、`ninja`、`nasm`。

```bash
sh build.sh
```

## 使用

### 服务端

```bash
./toom run                      # 前台运行，默认端口 4400
./toom run --port 4400 --log    # 写 toom.log
sudo ./toom install --port 4400 # systemd 服务，开机自启
sudo ./toom uninstall           # 停止并移除服务
./toom status --port 4400       # 房间、成员与流量
```

### 客户端

```bash
./toom                # 会议 TUI
./toom --json <json>  # 从 json 入会
```

创建房间拿会议码，或用会议码加入。会议码就是入会凭证。TUI 拒绝在 tmux 里启动。

### 启动参数

| 选项 | 功能 |
|------|------|
| `--json <json>` | 应用配置字段并从 json 入会 |
| `-h, --help` | 帮助页 |
| `-V, --version` | 版本 |

### 快捷键

下表是默认键位，配置里的 `key_*` 字段可改。

| 键 | 功能 |
|------|------|
| `q` | 退出，3 秒内再按一次确认 |
| `m` | 麦克风开 / 关 |
| `Shift+M` | 扬声器静音 / 取消静音 |
| `c` | 摄像头开 / 关 |
| `a` | 系统音频共享开 / 关 |
| `s` | 共享菜单：显示器或窗口 |
| `p` | 设置：声音、画面、共享 |
| `↑` / `↓` | 音量增 / 减 |
| `l` | 循环网格与焦点布局；共享中切换共享画面与成员的位置 |
| `h` | 仅本地预览镜像 |
| `Tab` | 轮流切换焦点成员 |
| `i` | 显示并复制会议码 |
| `?` | 帮助页 |

## 配置

全部配置在 `~/.config/toom/config.json`，每次修改写回。`key_*` 字段是快捷键。摄像头设备、采集尺寸、帧率、码率、编码后端都是这里的设置项，不是启动参数。

## 限制

- 仅 IPv4，不做 NAT 穿透。服务端必须能被 UDP 直达
- 会议码是入会凭证
- 窗口共享需要 niri，目前只支持浮动窗口
